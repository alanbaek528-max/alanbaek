# alanbaek

## 치수 검사 스테이션 데모

초고압 변압기 구성품(345kV·765kV 부싱 플랜지, 부싱 터렛, 철심 클램프, 권선 누름링, 고압 리드) 입고 치수 검사 콘솔입니다.

`demo/index.html`을 브라우저에서 직접 엽니다. 빌드 단계는 없습니다.

3D 뷰는 CDN으로 Three.js를 사용하므로 페이지를 여는 동안 인터넷 연결이 필요합니다. 측정값과 스캔은 시뮬레이션입니다.

## 작업 공정 공유 · 시험 결선

`demo/process.html`에서 공장 공정 흐름을 공유합니다. **시험 결선** 단계를 선택하면 진행 중인 시험마다 설명, 결선 요령, 위험 요소, 통제 조치가 표시됩니다.
