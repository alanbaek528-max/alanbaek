# 3D 스캐너 치수 검사 스테이션 — 작업 정리

작성일: 2026-10-23  
저장소: https://github.com/alanbaek528-max/alanbaek  
브랜치: `cursor/inspection-station-demo-5951`  
PR: https://github.com/alanbaek528-max/alanbaek/pull/1

이 문서는 지금까지 만든 이해관계자 데모를 PC 프로젝트로 옮기기 위한 정리입니다. 실제 스캐너나 서버는 연결되어 있지 않습니다.

## 무엇을 만들었나

공장 입고 치수 검사용 운전원 콘솔 컨셉입니다. 대상은 초고압 변압기 구성품(345kV, 765kV)입니다. 화면 문구는 한국어입니다.

정적 HTML이라 빌드가 없습니다. `demo/index.html`을 브라우저로 열면 됩니다. 3D 뷰만 CDN의 Three.js r128과 OrbitControls를 쓰므로, 페이지를 여는 동안 인터넷이 필요합니다.

GitHub 웹사이트에서 `index.html`을 누르면 소스만 보이고 실행되지 않습니다.

## PC로 받는 방법

폴더 `C:\Coding Project\3D Scan Inspection System` 이 비어 있다면 PowerShell에서 다음을 실행합니다.

```powershell
cd "C:\Coding Project\3D Scan Inspection System"
git clone --branch cursor/inspection-station-demo-5951 --single-branch https://github.com/alanbaek528-max/alanbaek.git .
```

받은 뒤 `demo\index.html`을 브라우저로 엽니다. 이후 작업은 Cursor에서 그 폴더를 열면 됩니다.

클라우드 작업 세션에서는 이 PC 경로가 보이지 않아, 파일을 `C:\`에 직접 복사하지는 못했습니다.

## 파일

| 경로 | 역할 |
| --- | --- |
| `demo/index.html` | 화면 뼈대. 이 파일을 연다. |
| `demo/css/station.css` | 다크 운전원 콘솔 스타일 |
| `demo/js/station.js` | 작업 데이터, 판정, 3D 형상, 버튼 동작 |
| `README.md` | 여는 방법 짧은 안내 |

부품, 기준 치수, 측정값, 공차, 3D 형상은 모두 `demo/js/station.js`의 `JOBS`와 `buildClamp`, `buildTurret`, `buildFlange`, `buildPressRing`, `buildLead`에 있습니다.

## 화면

- 상단: 초고압 변압기 · 부품 입고 검사, 스테이션 `TR-01`, 스캐너 `SIM-SCAN 08`, 작업자 박서연
- 왼쪽: 검사 작업 5건. 작업을 누르면 형상과 기준 치수가 바뀌고, 이미 검사한 작업은 판정 상태가 유지됩니다.
- 가운데: 3D 뷰. 드래그로 회전, 휠로 확대, 시점 초기화. 스캔 전에는 금속색, 스캔 중에는 레이저와 진행률, 스캔 후에는 편차 컬러맵입니다.
- 컬러맵: 청색 음편차, 녹색 공차 근처, 적색 양편차. 눈금은 -0.15 ~ +0.15 mm입니다.
- 오른쪽 카드: 종합 판정(대기 / 스캔 중 / 합격 / 불합격)과 확정 도장
- 아래 표: 항목, 기준값, 측정값, 공차, 편차, 판정. 단위는 mm입니다.
- 버튼: 스캔 시작, 재검사, 판정 확정

## 샘플 부품

수치는 1회 스캔 기준입니다. 재검사는 같은 식에 작은 흔들림을 더합니다.

| 도면 | 부품 | 재질 / 공정 | 1회 스캔 |
| --- | --- | --- | --- |
| CCL-345 | 345kV 철심 클램프 | SS400 / 용접 후 가공 | 합격 |
| TRT-765 | 765kV 부싱 터렛 | SS400 / 용접·가공 | 불합격. 포켓 내경 310.078 (기준 310, 공차 ±0.040) |
| BSF-345 | 345kV 부싱 플랜지 | A105 / 단조·선삭 | 합격 |
| WPR-345 | 345kV 권선 누름링 | SS275 / 선삭 | 합격. 재검사하면 외경이 공차 초과로 불합격 |
| HVL-765 | 765kV 고압 리드 | C1100 / 인발·가공 | 불합격. 단자 B 직경 49.968 (기준 50, ±0.021), 단차 위치 380.061 (기준 380, ±0.050) |

클램프 치수: 길이 1480, 폭 220, 판 두께 32, 체결홀 26, 홀 피치 420, 장착면 평탄도.  
터렛 치수: 플랜지 폭 640, 플랜지 높이 480, 포켓 내경 310, 포켓 깊이 220, 장착면 평탄도, 볼트 피치원 520.  
플랜지 치수: 외경 540, 내경 280, 두께 36, 피치원 460, 볼트홀 22, 가스켓면 평탄도.  
누름링 치수: 외경 640, 두께 48, 내경 410, 단차 깊이 12, 볼트 피치원 560, 평면 평탄도.  
리드 치수: 전장 2450, 단자 A 직경 60, 단자 B 직경 50, 단차 위치 380, 단자 폭 32, 진원도.

형상 공차(평탄도, 진원도)는 기준값 0, 공차는 상한(`≤`)입니다. 나머진 양측 공차(`±`)입니다. 한 항목이라도 공차 밖이면 종합 판정은 불합격입니다.

## 버튼 동작

- 대기일 때만 스캔 시작이 됩니다. 약 2.6초 동안 표면 데이터 수집, 기준 모델 정합, 편차 계산, 공차 비교 순서로 진행률이 올라갑니다.
- 검사가 끝나면 스캔 시작은 비활성화되고 재검사와 판정 확정이 활성화됩니다.
- 판정 확정은 시각과 도장을 남깁니다. 재검사하면 확정이 해제되고 다시 스캔합니다.
- 스캔 중에 다른 작업을 누르면 진행 중인 스캔은 취소되고 이전 상태가 남습니다.
